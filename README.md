# Student Academic Performance Analysis

## 📌 Project Overview

This project performs an Exploratory Data Analysis (EDA) on student academic performance data to identify the factors that influence students' final grades.

The analysis explores student demographics, family background, study habits, and academic performance using Python and data visualization techniques.

## 🎯 Objectives

- Analyze the student academic performance dataset
- Identify important factors affecting final grades
- Explore relationships between student characteristics and academic outcomes
- Perform data cleaning and exploratory data analysis
- Visualize important patterns and relationships
- Apply machine learning techniques for student performance prediction

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 📊 Key Analysis

The project includes:

- Dataset exploration
- Data quality checking
- Missing-value analysis
- Duplicate-value analysis
- Categorical feature analysis
- Numerical feature analysis
- Correlation analysis
- Data visualization
- Feature importance analysis
- Student performance prediction

## 🔍 Key Insights

The analysis shows that factors such as previous academic performance, absences, study time, and other student-related characteristics can have an influence on academic performance.

Feature importance analysis was also performed to identify the variables that contribute most to predicting the final grade.
